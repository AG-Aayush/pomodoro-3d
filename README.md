## Installation & Local Setup
Clone the repository:

## Bash
git clone [https://github.com/AG-Aayush/pomodoro-3d.git](https://github.com/AG-Aayush/pomodoro-3d.git)
Navigate to the folder:

## Bash
cd pomodoro-3d
Open index.html:
Simply open the index.html file in any modern web browser.

## Usage
Select your mode (Focus, Short Break, or Long Break).

Use the + and − buttons in the sidebar to adjust durations if needed.

Click START to begin your session.

Rotate the 3D apple by clicking and dragging on the canvas area.
